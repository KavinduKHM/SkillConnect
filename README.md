# SkillConnect - Community Skill-Exchange & Micro-Learning Platform

## Project Structure


## Tech Stack

### Backend
- Node.js + Express.js
- PostgreSQL + Prisma ORM
- JWT Authentication
- Cloudinary (File Upload)

### Mobile
- React Native + Expo
- React Navigation
- Axios + React Query
- Zustand (State Management)

## Setup Instructions

1. Clone the repository
2. Copy .env.example to .env in backend folder
3. Run 
pm install in both ackend/ and mobile/ folders
4. Run 
px prisma migrate dev in backend
5. Start backend: 
pm run dev in backend
6. Start mobile: 
pm start in mobile
